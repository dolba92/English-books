Нужно полностью преобразовать ТЕКУЩЕЕ существующее приложение в новое современное веб-приложение для чтения английских книг:

ENGLISH BOOKS

ВАЖНО:
НЕ создавай второй проект рядом.
НЕ начинай приложение заново, если это уничтожит уже работающие функции текущего проекта.
Работай с существующим проектом и постепенно преобразуй его в English Books.

Основная идея:

English Books = красивая современная читалка английских книг
+ существующий уже работающий перевод слов
+ существующий уже работающий перевод предложений
+ сохранение выбранных слов
+ экспорт сохранённых слов в TXT.

Встроенные тренировки здесь больше НЕ нужны.

Главный приоритет:
СДЕЛАТЬ ОТЛИЧНУЮ ЧИТАЛКУ.

==================================================

В текущем приложении уже хорошо работает перевод слов и предложений.

ЭТА ЛОГИКА ДОЛЖНА ОСТАТЬСЯ В ТЕКУЩЕМ ВИДЕ.

Считай существующую translation logic READ-ONLY.

НЕ:

- переписывай translation service;
- меняй translation API;
- меняй providers;
- меняй fallback chain;
- меняй алгоритм выбора перевода;
- меняй обработку контекста;
- добавляй новые translation providers;
- устанавливай новые библиотеки для перевода;
- добавляй собственный stemming;
- добавляй новую lemmatization;
- рефактори переводчик "для улучшения";
- оптимизируй его архитектуру;
- меняй существующий sentence translation;
- меняй существующий word translation.

При создании нового Reader и нового UI нужно только ПОДКЛЮЧИТЬ существующую работающую функцию перевода.

Если новому интерфейсу нужен adapter, создай минимальный adapter вокруг существующей translation logic, не меняя её внутреннюю работу.

Не пытайся "сделать перевод ещё лучше".

Главное правило:

OLD TRANSLATION LOGIC = READ ONLY.

До начала большой переделки проверь несколько слов и предложений и зафиксируй текущее рабочее поведение.

После переделки повтори те же проверки.

Результат перевода должен остаться таким же.

==================================================
2. НАЗНАЧЕНИЕ НОВОГО ENGLISH BOOKS
==================================================

Это приложение для изучения английского через чтение настоящих книг.

Основной сценарий:

пользователь загружает EPUB или FB2
→ книга появляется в библиотеке
→ пользователь открывает её
→ читает удобными страницами
→ нажимает на незнакомое английское слово
→ получает перевод через СУЩЕСТВУЮЩУЮ систему
→ может прослушать слово
→ может добавить слово в "Сохранённые слова"
→ продолжает чтение.

Также пользователь может использовать существующую функцию перевода полного предложения.

Сохранённые слова пользователь позже переносит в отдельное приложение English Card.

Поэтому в English Books НЕ нужна отдельная система обучения.

5. НОВЫЙ ДИЗАЙН
==================================================

Полностью обновить внешний вид приложения.

Дизайн должен быть:

- уютным;
- взрослым;
- эстетичным;

70–80%:
белый / молочный / очень светлый кремовый;

шоколадный / тёмно-коричневый;

5–10%:
мягкий приглушённый светло-розовый.

Розовый использовать только как акцент.

Основной текст:
тёмный шоколадный / почти чёрный.

Вторичный текст:
контрастный серо-коричневый.

НЕ делать:

- огромные ярко-розовые поверхности;
- full-screen pink gradients;
- множество розовых карточек;
- плохо читаемый светлый текст;
- чрезмерный glassmorphism;
- огромные тени;
- толстые рамки;
- гигантские заголовки;
- перегруженные панели;
- слишком много декоративных элементов.

14. РЕАЛЬНЫЙ ПРОГРЕСС КНИГИ
==================================================

Не использовать фейковое количество страниц.

Для электронной книги количество страниц зависит от:

- размера Reader;
- шрифта;
- font size;
- line height;
- ширины страницы.

Поэтому основной устойчивый прогресс хранить через semantic position.

Например:

chapter + text offset / CFI / equivalent.

Процент:

прочитанная semantic position / общий объём книги.

Visual page X of Y можно показывать внутри Reader для текущих настроек.

Но не использовать случайное "примерное количество страниц" на карточке книги.
