При импорте сначала найти OPF package document.

Затем определить cover image через стандартные EPUB способы.

Поддержать EPUB 3: manifest item с properties=“cover-image”

Поддержать EPUB 2: metadata:
где content указывает на id соответствующего manifest item.

Также учитывать: - manifest; - guide reference type=“cover”; -
корректное разрешение relative href; - директорию OPF; - URL encoding; -
media-type; - разные расширения JPG/JPEG/PNG/WebP; - вложенные папки

Нужно открыть/разобрать эту cover page и найти реальное изображение

и использовать именно image resource.

Не использовать случайно: - первую страницу книги; - title page; -

cover cover-image frontcover front-cover

и изображения с подходящими пропорциями книжной обложки.

Существующий перевод НЕ МЕНЯТЬ.

При click/tap на английское слово использовать существующий word lookup.

Popup визуально привести к новому стилю: - светлая карточка; - English
word; - 🔊; - основной перевод; - существующие части речи/значения; - +
В слова.

Popup должен автоматически выбирать позицию: сверху или снизу слова в
зависимости от свободного места.

Не выходить за viewport. Не перекрывать выбранное слово без
необходимости.

================================================== 33. ПЕРЕВОД
ПРЕДЛОЖЕНИЯ ==================================================

Существующую translation logic НЕ менять.

При выборе/нажатии предложения открывать панель.

Desktop: right-side drawer.

Вверху tabs: Перевод Грамматика

Original sentence.

Ниже translation или grammar information.

Закрытие панели возвращает Reader к нормальной ширине. Текстовая позиция
не меняется.

================================================== 34. GRAMMAR
==================================================

Существующую grammar logic НЕ менять.

Сохранить существующую информацию: тип предложения; время; залог;
объяснение.

Можно только улучшить визуальную подачу.

================================================== 35. MOBILE READER
==================================================

Mobile Reader должен быть специально адаптирован, а не просто
уменьшенной desktop страницей.

Target widths примерно: 360–430 px.

На телефоне во время чтения: НЕТ desktop sidebar.

Reader занимает почти весь экран. Небольшие horizontal margins.
Компактная верхняя панель.

Основные controls: Back Contents Aa Fullscreen/immersive

Навигация: tap left/right и swipe horizontal.

Не требовать попадать пальцем в маленькую стрелку.

================================================== 36. MOBILE READER
SETTINGS ==================================================

На телефоне Aa не открывает узкую desktop panel.

Открывать bottom sheet или почти fullscreen sheet.

Внутри те же настройки: font; size; weight; alignment; paragraphs; page;
illustrations; theme.

Sheet должен нормально scroll.

После закрытия пользователь остаётся на том же месте книги.

================================================== 37. MOBILE WORD POPUP
==================================================

Word popup никогда не должен выходить за границы экрана.

Если около слова недостаточно места: показать компактный bottom sheet.

Сохранить быстрый доступ: перевод произношение + В слова.

================================================== 38. MOBILE SENTENCE
TRANSLATION ==================================================

Translation/Grammar panel на mobile показывать как удобный bottom sheet
или fullscreen sheet.

Не пытаться одновременно разместить книгу и desktop right drawer на 390
px.

После закрытия возвращаться к тому же месту чтения.

================================================== 39. MOBILE LIBRARY
==================================================

На телефоне desktop sidebar отсутствует.

Использовать bottom navigation: Библиотека Слова Прогресс Настройки

Сделать компактные icons + labels.

Библиотека: 1–2 карточки книги в строку в зависимости от ширины.

Обложки должны оставаться хорошо видны.

Hero сильно компактнее desktop.

Кнопка + Добавить книгу доступна без долгой прокрутки.

Никакого horizontal overflow.

================================================== 40. PROGRESS
==================================================

Оставить раздел Progress.

Полностью удалить из него тренировочную/SRS информацию.

Показывать только реальные reading данные, если они действительно
доступны: прочитанные книги; читаемые книги; reading progress; время
чтения; сохранённые слова; reading days/streak, если это реально
рассчитывается.

Не создавать fake statistics.

================================================== 41. ОБЩИЕ SETTINGS
==================================================

Общая страница Settings больше не должна быть главным местом изменения
Reader.

Reader settings доступны через Aa.

В общей Settings оставить только полезные глобальные параметры: default
reading settings; pronunciation/voice, если уже поддерживается;
interface preferences; data/storage management; reset preferences.

Полностью убрать SRS.

================================================== 42. ХРАНЕНИЕ ДАННЫХ
==================================================

Не удалять существующие: загруженные книги; reading progress;
сохранённые слова; обложки; settings.

Если для нового UI нужно изменить storage schema: сделать migration
существующих данных.

Не очищать IndexedDB/localStorage пользователя ради удобства разработки.

================================================== 43. VERCEL
==================================================

Проект должен быть обычным web application, пригодным для deployment на
Vercel.

Не привязывать новый UI к Replit-specific runtime. Не добавлять
Replit-only dependency для основных функций.

Особенно: НЕ менять существующую translation architecture ради Vercel.

Она уже работает. Сохранить её.

================================================== 44. ЧТО ДОЛЖНО
ПОЛУЧИТЬСЯ В ИТОГЕ ==================================================

English Books должен ощущаться прежде всего как качественная современная
электронная читалка для изучения английского.

LIBRARY: красивый существующий background; компактный hero; логотип
English Books; аккуратная grid книг; настоящие EPUB covers; красивые
fallback covers; никакой деревянной клетки вокруг книг.

READER: почти весь экран отдаётся книге; sidebar скрыт; чистый текст;
правильная pagination; текст не обрезается; нормальные пробелы;
Contents; Aa; Fullscreen; tap/click/swipe navigation; позиция чтения
сохраняется.

READER SETTINGS: открываются непосредственно во время чтения; desktop
right drawer; mobile bottom sheet; настройки применяются сразу; font;
size; weight; alignment; paragraphs; page width; margins; illustrations;
themes.

WORDS: никаких тренировок; список сохранённых слов; выбор слов;
удаление; TXT export.

TRANSLATION: оставить существующий быстрый и качественный перевод слов.

SENTENCE TRANSLATION: оставить существующую реализацию.

GRAMMAR: оставить существующую реализацию.

MOBILE: не уменьшенная desktop версия, а полноценный удобный мобильный
Reader.

================================================== ФИНАЛЬНОЕ ОГРАНИЧЕНИЕ
==================================================

Это единая задача на полный редизайн и завершение English Books.

Не останавливайся после изменения одного экрана. Не отвечай, что
остальные пункты можно сделать следующим этапом.

Реализуй весь описанный UI/UX в текущем проекте за этот проход.

При этом НЕ переписывай работающие translation/grammar systems.

Главная идея:

СОХРАНИТЬ ТО, ЧТО УЖЕ РАБОТАЕТ ХОРОШО: перевод слов, перевод
предложений, грамматику, существующие книги и данные.

И ПОЛНОСТЬЮ ПЕРЕДЕЛАТЬ ТО, ЧТО СЕЙЧАС ВЫГЛЯДИТ И РАБОТАЕТ ПЛОХО:
Library, covers, navigation, Words, Reader, Reader Settings, fullscreen,
pagination, responsive/mobile UI.

Результат должен быть цельным приложением ENGLISH BOOKS, а не смесью
старого Love Texas и нового дизайна.

НЕ ЗАВЕРШАЙ ЗАДАЧУ, ПОКА НЕ ВЫПОЛНЕНЫ ВСЕ ПУНКТЫ ЭТОГО ФАЙЛА.
